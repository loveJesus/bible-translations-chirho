## Particle Conventions

Use n-dash (–) for bound elements:
- Articles: "el–cielo", "la–tierra"
- Prepositions: "en–principio", "sobre–faz"

## Grammar Notes

1. **Word Order**: SVO default in Spanish
   - Preserve emphasis from original where possible
   - Allow flexibility for natural flow

2. **Gender/Number**: Spanish has m/f and singular/plural
   - Dios (m.), el Señor (m.)
   - Match divine references appropriately

3. **Articles**: Definite (el/la/los/las) and indefinite (un/una)
   - "el Señor" (the Lord)
   - Use n-dash when bound to original word

4. **Formal/Informal**: Use formal register
   - Usted forms for deity
   - Reverential language
