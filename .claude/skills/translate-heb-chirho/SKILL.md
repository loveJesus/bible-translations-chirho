# Modern Hebrew (עברית) Translation Skill

## Script: Hebrew

Use Hebrew script (עברית). Text direction is RTL (right-to-left).

**Note**: This skill is for translating Greek NT into Modern Hebrew, not for Hebrew OT which is already in Hebrew.

## Particle Conventions

Hebrew has prefixed particles:
- Definite article: הַ (ha-)
- Conjunction: וְ (ve-)
- Prepositions: בְּ (be-), לְ (le-), מִ (mi-), כְּ (ke-)

Use n-dash when representing Greek bound morphemes distinctly.

## Grammar Notes

1. **Word Order**: VSO/SVO flexible
   - Can match Greek order often

2. **Definiteness**: Use הַ appropriately
   - Greek article → Hebrew הַ

3. **Binyanim**: Choose appropriate verb pattern
   - Qal, Nifal, Piel, Pual, Hifil, Hufal, Hitpael

4. **Construct State (סמיכות)**: For genitive relationships
   - "עֶבֶד הַמָּשִׁיחַ" (servant of the Messiah)
