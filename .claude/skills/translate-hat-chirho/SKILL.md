# Haitian Creole (Kreyòl Ayisyen) Translation Skill

## Script: Latin

Latin alphabet with Haitian Creole orthography: è, ò, ñ (or ny).

## Divine Names

| Original | Kreyòl | Notes |

## Grammar Notes

- SVO word order
- No conjugation (TMA markers)
- Post-posed definite article: la, lan, a, an
