## Particle Conventions

Korean has postpositional particles (조사):
- Subject: 이/가 (i/ga)
- Topic: 은/는 (eun/neun)
- Object: 을/를 (eul/reul)
- Possessive: 의 (ui)
- Location: 에/에서 (e/eseo)

Use n-dash for representing bound Greek/Hebrew morphemes.

## Grammar Notes

1. **Word Order**: SOV
   - Verb always final
   - Modifiers precede head

2. **Honorifics**: Essential in Korean
   - 하나님 (God - already honorific)
   - 주님 (Lord + honorific)
   - Use 높임말 (formal speech) for deity references

3. **Speech Levels**: Use formal written style
   - 하십시오체 or 합쇼체 for scripture
   - Maintains reverence

4. **No Articles**: Korean lacks articles
   - Context determines definiteness
