# Burmese (မြန်မာ) Translation Skill

## Script: Myanmar

Use Myanmar script (မြန်မာအက္ခရာ).

| יהוה (YHWH) | ယေဟောဝါ | Yehowa |

| אדני (Adonai) | သခင် | Thakhin (Lord) |
| Χριστός | ခရစ်တော် | Khrit Taw (Christ) |
