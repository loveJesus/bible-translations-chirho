## Noun Class System

Swahili has 18 noun classes. Key ones for biblical text:

| Class | Prefix | Example | Used for |
|-------|--------|---------|----------|
| 1/2 | m-/wa- | mtu/watu | People |
| 3/4 | m-/mi- | mti/miti | Trees, natural |
| 5/6 | ø/ma- | jiwe/mawe | Augmentatives |
| 7/8 | ki-/vi- | kitu/vitu | Things |
| 9/10 | n-/n- | nyumba | Animals, loanwords |
| 11 | u- | ukuta | Long/thin things |

Agreement markers must match noun class throughout sentence.

## Particle Conventions

Swahili is agglutinative with prefixes:
- Subject prefix: ni-, u-, a-, tu-, m-, wa-
- Tense markers: -na- (present), -li- (past), -ta- (future)
- Object infix: -m-, -ku-, etc.

## Grammar Notes

1. **Word Order**: SVO
   - But heavily marked by verb morphology

2. **Verb Morphology**: Complex
   - Subject-Tense-Object-Root-Extension-Mood
   - Example: ni-li-m-pend-a (I loved him)

3. **Concord**: Essential
   - All modifiers agree with noun class
