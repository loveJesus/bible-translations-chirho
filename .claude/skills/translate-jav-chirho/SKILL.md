# Javanese (Basa Jawa) Translation Skill

## Script: Latin

Latin alphabet (modern Javanese). Historic Javanese script (Aksara Jawa) also exists.

## Speech Levels

Javanese has distinct speech levels:
- **Ngoko**: Informal/intimate
- **Krama**: Formal/respectful
- **Krama Inggil**: Highly respectful (for deity)

Use Krama Inggil for deity references.
