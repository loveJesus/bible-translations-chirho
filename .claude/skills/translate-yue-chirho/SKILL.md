## Cantonese-Specific Characters

Some characters unique to written Cantonese:
- 嘅 (ge3) - possessive
- 係 (hai6) - to be
- 喺 (hai2) - at/in
- 冇 (mou5) - not have

For word-by-word translation, prefer standard Chinese where possible.

## Grammar Notes

1. **Word Order**: SVO
   - Similar to Mandarin

2. **Aspect Markers**: Cantonese-specific
   - 咗 (zo2) - completed
   - 緊 (gan2) - progressive
   - 過 (gwo3) - experiential

3. **Final Particles**: Convey nuance
   - 啦、喎、㗎、囉

4. **Classifiers**: Same system as Mandarin
   - 一個人 (one person)
